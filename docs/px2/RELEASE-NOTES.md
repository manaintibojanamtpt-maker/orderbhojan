# PX2 Release Notes — 0.9.0-px2

## Summary

PX2 implements the approved PX1.5 design freeze as production React UI via BDS v1.1-px2. This is a visual-only milestone; checkout and order composer (M7) remain blocked.

## Highlights

- Warm **food** theme as default
- 40vh immersive home hero with in-hero search
- Restaurant immersive hero with floating menu CTA
- Menu **FoodRow** horizontal cards
- Premium search, nav island, and empty states
- Removed milestone/mock copy from consumer-facing screens

## Upgrade

```bash
cd orderbhojan && npm run gate:px2
```
