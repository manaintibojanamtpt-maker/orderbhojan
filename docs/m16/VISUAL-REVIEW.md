# M1.6 Visual Review

## Design Intent

Elevate Mana Inti Bojanam warmth into a flagship marketplace — food-first, edge-to-edge, glass-native.

## Key Visual Changes (M1.5 → M1.6)

| Element | Before | After |
|---------|--------|-------|
| Layout | Boxed 48rem column | Fluid up to 90rem, edge-bleed hero |
| Header | Static surface card | Transparent → glass on scroll |
| Search | Flat input | Gradient shell, floating elevation |
| Hero | Small rounded card | Full-bleed cinematic carousel |
| Categories | Basic chips | Morph pills with spring scale |
| Restaurant cards | Bordered card box | Borderless shadow, hover lift |
| Bottom nav | Full-width bar | Floating glass island |
| Typography | Standard BDS | Tighter display hierarchy |

## BDS Compliance

All interactive elements remain `@bhojan/design-system` components. Premium layer is CSS + layout classes only (`ob-*`, `ob-premium-*` tokens in CSS variables).

## Reference Alignment

- **Mana Inti:** Warm orange gradients, appetite-forward photography
- **Apple / Airbnb craft:** Glass, spacing, motion restraint
- **Uber / Linear:** Floating chrome, native navigation island
