# PX1 Visual Certification

**Program:** PX1  
**Stage:** 5 — Visual Certification  
**Threshold:** **9.5 / 10 minimum per category** — any score below fails  
**Status:** Framework — pending Stage 4 implementation

---

## Final review question

> *If this screenshot appeared in the App Store today with no logo, would people assume it belongs to a world-class consumer technology company?*

**Per screen:** YES required for pass.  
**No screenshot = not certified.** Internal reports alone do not count.

## Certification process

1. QA captures annotated screenshots per matrix
2. DRB scores independently (3 reviewers minimum)
3. Average per category; any <9.5 → screen rejected
4. Rejected screens return to Phase 3/4 implementation
5. Re-certify until pass
6. CEO + PM + ARB + DRB unanimous sign-off
